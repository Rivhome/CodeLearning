# C++ Primer 学习项目

这是一个基于《C++ Primer》教材的学习项目，包含所有章节的练习代码。

## 项目结构

```
cpp_primer/
├── .vscode/          # VSCode 配置文件
├── build/            # 编译产物目录（按章节分组）
│   └── chapter01/   # 第一章的编译产物
├── include/          # 共享头文件
│   └── Sales_item.h
├── src/              # 源代码
│   └── chapter01/   # 第一章练习
│       ├── 1.3/     # 练习 1.3
│       │   └── ex_1.3_main.cpp
│       ├── 1.4/     # 练习 1.4
│       │   └── ex_1.4_main.cpp
│       └── ...
└── README.md         # 本文件
```

## 使用方法

### 编译和运行

**方法 1: 使用 F5 调试**
1. 打开任意练习文件（如 `src/chapter01/1.3/ex_1.3_main.cpp`）
2. 按 `F5` 键启动调试
3. 程序会自动编译并运行

**方法 2: 使用 Code Runner**
1. 右键点击源代码文件
2. 选择 "Run Code"
3. 程序会在输出面板中显示结果

**方法 3: 使用构建任务**
1. 打开源代码文件
2. 按 `Ctrl+Shift+B` 编译
3. 编译产物会在 `build/chapter01/` 目录中

## 编译环境

- 编译器：MinGW-w64 g++ 8.1.0
- C++ 标准：C++17
- IDE：Visual Studio Code

## 注意事项

- 每个练习都是独立的程序，可以单独编译运行
- 共享头文件存放在 `include/` 目录中
- 编译产物按章节组织在 `build/` 目录中
- `.vscode/` 配置文件会自动处理 include 路径
